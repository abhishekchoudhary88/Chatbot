# 🤖 Kimi Model AI Chatbot & Vision Studio Pro

Welcome to the **Kimi Model AI Chatbot & Vision Studio Pro**! This project is a premium, next-generation AI interface featuring a stunning Glassmorphism UI. It serves as an advanced frontend client built to interact with powerful AI models (like Kimi, OpenAI, etc.) for both text-based conversations and deep image analysis.

## ✨ Key Features

### 💬 Chat Studio (Text & Voice)
* **Voice Typing (Speech-to-Text):** Integrated Web Speech API allows users to speak their prompts directly into the chat via the Mic (🎤) button.
* **Markdown Support:** Renders AI responses beautifully with bold text, lists, and formatted code blocks using `marked.js`.
* **Export Conversation:** One-click "Export Chat" feature to download the entire conversation history as a `.txt` file.
* **Smart Copy:** Instantly copy AI responses to your clipboard with a single click.

### 🖼️ Vision Studio Pro (Image Analysis)
* **Drag & Drop Zone:** Modern file upload area supporting both drag-and-drop and standard file browsing.
* **Multiple Analysis Modes:** Options for 'Deep Analysis', 'Caption Generation', and 'Object Detection'.
* **Live Image Preview:** See the image clearly before sending it to the AI model.

### 🎨 Premium UI/UX
* **Glassmorphism Design:** Translucent backgrounds, blur effects, and modern gradients.
* **Dark & Light Mode Toggle:** Fully responsive themes adapting to user preference.
* **Custom Animations:** Smooth sliding sidebars, typing indicators, pulse effects on recording, and toast notifications.
* **No-Reload Architecture:** Seamlessly switch between the Chat Studio and Vision Studio without refreshing the page.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Advanced Animations, Custom Variables, CSS Grid/Flexbox)
* **Scripting:** Vanilla JavaScript (ES6+)
* **Libraries:** `marked.js` (for Markdown parsing)
* **Browser APIs:** Web Speech API (for Voice Recognition)
